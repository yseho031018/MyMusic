# My Music Android

가사 화면은 MP3 내장 가사를 우선 사용하고, 없으면 LRCLIB에서 검색합니다. 싱크 가사가 있으면 재생 시간에 맞춰 각 줄을 강조합니다.

영어·일본어 가사는 원문과 한글 발음을 표시합니다. 한글 발음은 참고용이며 노래의 실제 발음과 다를 수 있습니다. 일본어 발음에는 Kuromoji IPADIC 읽기 사전, 영어 발음에는 CMU Pronouncing Dictionary를 사용합니다.

싱크 가사는 LRC의 `[offset:...]` 시간을 적용합니다. 가사 화면 우측 상단 메뉴에서 곡마다 0.5초씩 싱크를 조절하고 초기화할 수 있습니다. 영어 발음 사전의 저작권 고지는 앱 에셋의 `CMUDICT-LICENSE`에 포함되어 있습니다.
